# CyA-2627-Practica1-ContenedoresAsociativos
El objetivo de la practica es trabajar con algunas estructuras de datos basicas en C++ y que seran de especial relevancia a la hora de desarrollar las practicas de la asignatura. En particular, nos centraremos en el uso de los contenedores asociativos de la biblioteca estandar de C++ (Standard Template Library, STL).
